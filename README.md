# Transcrit-AI
## 🗣️ Aplicativo de Trancrição com AI

<img width="1841" height="990" alt="Image" src="https://github.com/user-attachments/assets/6c981347-01e9-4e3a-ad56-ae62ef87cef3" />

### 🛠️ Ferramentas
- LangChain
- Groq API
- Electron

---

O aplicativo foi feito para transcrever audios .MP3 ou Gravados em tempo real com o Microfone, usando scripts com ajuda do Langchain e do modelo de IA da Groq de forma gratuita, além de poder resumir o conteudo com base no contexto.
